## New

### Notes that can become tasks

Converting a note into a task now removes the original note and opens the new task directly, keeping the workspace tidy and the next step close at hand.

Capture a thought quickly, organize it by category, and turn it into real work when it is ready.

Teammates can now comment on notes, with authors able to edit or remove their own comments.

### Contact management

Keep useful people, their details, and relevant context close to the work without reaching for another system.

Contacts are grouped by relationship—from brand partners and venues to media, talent, hospitality, and event vendors—so a growing network stays easy to scan.

### Favorite projects

Star frequently visited projects and reach them directly from the dashboard and sidebar.

## Improved

### Dynamic task filters

Tasks can now be included or excluded by category tags. Tag choices stay in sync with each category, so renamed, added, and removed tags are reflected automatically.

### Faster dropdowns

Dropdown menus now stay compact, include search, and keep your own profile close to the field when choosing an assignee or reporter.

Favorite projects now appear first when choosing a project while creating or editing a task.

### Linked task confirmations

Task creation and edit confirmations now include the task number as a direct link, making it easy to jump straight to the work you just changed.

### Linked task references

Ticket keys in comments, such as RMT-123, now link directly to the referenced task when it exists.

### Threaded comments

Comments now support nested replies, making it clear which message a teammate is responding to while keeping the full conversation together.

### Focused task editing

Editing from a task page now stays focused on task fields while checklist items, attachments, comments, and activity remain on the page where they are already available. On wide screens, task details and activity stay in view while the main task work scrolls.

### Safer task edits

Changing one task field now keeps its existing schedule and all other untouched details intact.

Tasks also remain visible on category-filtered boards when their project is changed.

### A more useful dashboard

A responsive masonry layout brings assigned work, drafts, deadlines, favorites, and activity into clearer groups.

### Resource management

Projects, categories, notes, and contacts now share clearer layouts and more consistent editing patterns. Supporting links, notes, and attachments are easier to reorder on touch, pointer, and keyboard devices, and supporting notes now include rich Markdown formatting.

Modal headers and action bars now stay in place while longer content scrolls between them.

Edit, archive, and delete icon buttons now use consistent colors throughout the workspace, making common actions easier to recognize at a glance. Empty projects and categories can now be permanently deleted, while archived items use a cleaner badge treatment.

### Workspace activity

Activity now captures changes to projects, categories, notes, contacts, and attachments alongside task updates.

### Category access and ownership

Owners can understand category visibility more easily and manage responsibility with explicit controls.

### Responsive workspace navigation

Navigation, forms, cards, and task columns make better use of phones, tablets, and wide desktop screens.
